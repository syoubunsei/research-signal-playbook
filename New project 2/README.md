# Research Signal Playbook

A Codex skill for fast, signal-first market and competitor research.

It is designed for situations where you need more than a static landscape summary. The workflow emphasizes recent movement, product mechanics, distribution clues, risks, and action recommendations.

## What this skill is for

Use it to research:

- a market category
- a competitor set
- an emerging product trend
- a single product worth deep-diving
- a product or growth opportunity window

## What makes it different

This skill is built around a specific working style:

- start from live signals, not only desk research
- treat distribution and social chatter as evidence
- separate facts, signals, patterns, and implications
- push every report toward decisions and next moves

## Core workflow

1. Frame the research question
2. Build the sample set
3. Collect signal layers
4. Separate facts, signals, patterns, and implications
5. Analyze with reusable lenses
6. Synthesize a point of view
7. End with action recommendations

## Suggested use cases

- "Summarize the AI companion category and tell me where the opportunity is."
- "Compare these three competitors and identify the strongest spread mechanics."
- "Analyze why this product is suddenly getting attention."
- "Turn these notes and links into a strategy memo."
