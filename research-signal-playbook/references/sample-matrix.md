# Sample Matrix

Use this matrix to normalize competitor inputs before writing conclusions.

| Product | Company | Positioning | Target User | Platform | Pricing | Recent Momentum | Key Hook | Key Risk | Notes |
|---|---|---|---|---|---|---|---|---|---|

## Suggested Filling Rules

- `Positioning`: one sentence only
- `Target User`: describe the most obvious primary segment
- `Recent Momentum`: note the latest visible signal with a date if possible
- `Key Hook`: the single strongest adoption or spread driver
- `Key Risk`: the most important structural weakness
